# 键径 KeyPath

> 从基准键，到盲打自由。

键径是一款运行在 Windows 桌面上的键盘熟悉与打字练习应用，面向没有系统学习过盲打的人。它把键盘分区课程、实时手位提示、分级晋级和本地挑战放进同一个应用，帮助初学者从"找到 F 和 J"开始，逐步建立不看键盘输入的习惯。

应用不需要启动服务器，也不通过网址打开：界面由 Electron 直接加载安装目录内的页面文件。用户数据只写入本机一个 JSON 文件，全程离线。

## 一、项目解决什么问题

### 初学者真正遇到的困难

- **不知道手该放在哪里**：不熟悉基准键，打字时习惯低头找键，越练越依赖视觉。
- **不知道该用哪根手指**：知道字母位置，但手指分工混乱，速度和准确率很难同时提高。
- **课程跨度太大**：很多练习工具直接给一长段文章，初学者还没掌握基准键就被迫练习整句。
- **练完不知道有没有进步**：只看对错，看不到速度、准确率、星级和下一阶段目标。
- **在线工具带来额外负担**：注册账号、联网、上传成绩，练习数据不在自己手里。

### 键径的处理方式

- 把键盘拆成**基准键、上排、下排、左右手分区、数字排、Shift、标点、符号**等区域，用 16 节短课逐步覆盖。
- 练习时同时显示**下一个键、应该使用的手指和需要的对侧 Shift**，让手位提示跟着输入走。
- 按错键不会推进光标，也不会计为正确字符；必须按对当前字符才能继续，避免"一路回车"式无效练习。
- 每节课记录**星级、最佳速度、最佳准确率和练习次数**；每个等级有明确的四项晋级条件，满足后自动解锁下一级。
- 提供 30 秒、60 秒和 45 秒三种计时挑战，以及只保存在本机的积分榜。
- 所有数据保存在本机文件中，不依赖网络、账号或服务器；提供"清除全部数据"入口。

### 适合谁

适合第一次接触盲打、想从正确手位开始练习的 Windows 用户，也适合已经会用键盘但速度不稳定、希望用短课和挑战逐步提高的人。

课程文本使用英文，以便覆盖字母、数字和常用符号键位；界面和提示均为中文。应用不用于中文输入法练习、在线对战或专业打字考试训练。

## 二、主要功能

### 1. 六步入门指南

「入门指南」用六个步骤讲清练习前的准备：

1. 坐姿、屏幕距离和手腕位置；
2. 用 F、J 的凸起找到基准键；
3. 每根手指负责的列和颜色分工；
4. 上排、下排与数字排的伸展方式；
5. 空格由拇指负责，Shift 使用对侧手；
6. 四个等级的路线和晋级方式。

指南中的键位示意会高亮相关按键，最后可以直接开始第 1 课。

### 2. 16 节分区课程，四个等级

课程按难度和键盘区域拆分，每个等级 4 节，共 16 节：

| 等级 | 课程重点 |
| --- | --- |
| 入门 | 基准键、上排、下排、第一组高频词 |
| 中等 | 左手区、右手区、数字排、左右手混合词 |
| 老手 | Shift 大写、标点、常用词连打、完整短句 |
| 专家 | 代码符号、长句耐力、数字混排、综合段落 |

- 每节课都有独立的**目标 WPM、目标准确率和练习文本**，难度从 1 到 4 递增。
- 训练页显示总完成课程数、总星星数和最佳速度，并标记推荐课程。
- 已解锁等级的课程可以直接练习；未解锁等级可以先查看晋级要求，但课程按钮不可用。
- 完成当前等级的晋级条件后，下一等级自动解锁。

### 3. 实时虚拟键盘与按键反馈

- 高亮**下一个目标键**，同时显示该键对应的手指和颜色。
- 遇到大写字母或上档符号时，提示使用另一侧的 Shift。
- 每次按键都有正确/错误颜色反馈；顶部可以开启或关闭按键音效。
- 练习区实时显示速度（WPM）、准确率、用时、失误次数和连击数。
- 键盘在窄窗口中会自动横向滚动到当前目标键，避免目标键跑出视野。
- 练习文本按当前进度分窗口显示，长文本不会把整段内容挤在一屏里。

### 4. 三种计时挑战

| 挑战 | 时长 | 规则 |
| --- | --- | --- |
| 基准键冲刺 | 30 秒 | 只使用 A S D F G H J K L 和空格，尽量多、尽量准地输入 |
| 60 秒竞速 | 60 秒 | 输入随机排列的常用词，速度相同按准确率排名 |
| 无失误 45 秒 | 45 秒 | 最多允许 3 次失误，第 4 次失误立即结束 |

- 倒计时从**第一次输入字符**开始，时间结束自动结算。
- 每次开始挑战或点击「再来一局」都会重新生成挑战文本。
- 有效成绩会获得 XP；只有排名进入对应挑战前 10 名的成绩会保留在本地积分榜。
- 45 秒挑战虽然叫「无失误」，实际规则是最多 3 次失误；失败的一局不计入积分榜，也不获得 XP。

### 5. 本地积分榜与昵称

- 三个挑战各有独立榜单，每个榜单只保留本机前 10 名。
- 排序优先看 WPM，其次看准确率，最后看完成时间；榜单显示名次、玩家、速度、准确率和日期。
- 昵称最多 12 个字符，可在积分榜页修改；修改后，历史挑战记录中的名字也会同步更新。
- 可以单独清空某个挑战的全部记录；这只影响该挑战的榜单，不改变课程进度或已累计的 XP。
- 积分榜是单机排行榜，不会上传网络，也没有在线排名。

### 6. 单文件数据与隐私

- 昵称、音效设置、XP、课程星级、最佳成绩、练习次数和挑战记录全部写入一个 `keypath-data.json` 文件。
- 每次进度变化都会自动保存，没有单独的"保存"按钮。
- 应用不使用 localStorage、数据库、账号系统或网络请求。
- 具体路径、回退规则和清除方法见下方「五、本机数据与清除」。

## 三、安装方法

### 方式一：直接安装（推荐给普通用户）

如果拿到的是已经构建好的目录，双击运行：

```text
release/KeyPath-Setup-1.0.0.exe
```

也可以直接打开 [KeyPath-Setup-1.0.0.exe](<release/KeyPath-Setup-1.0.0.exe>)。

- 支持 **Windows 10 / 11 x64**。
- 按当前用户安装，不要求管理员权限；安装完成后会在桌面和开始菜单创建「键径 KeyPath」快捷方式。
- 应用运行时不联网，不需要浏览器，也不会启动本地服务器。
- 安装包未做代码签名，Windows SmartScreen 可能提示未知发布者，选择「更多信息 → 仍要运行」即可。
- 默认数据文件在安装目录中，卸载前建议先备份 `keypath-data.json`。

如果当前目录中没有 `release/` 安装包，请使用下面的源码方式运行或构建安装包。

### 方式二：从源码运行

环境要求：

- Windows 10 / 11 x64；
- Node.js **22.12 或更高版本**（包含 npm）。

在项目根目录执行：

```bash
npm install
npm run dev
```

`npm run dev` 会先构建前端资源，再启动 Electron 桌面窗口；它不会启动 HTTP 服务，也不需要打开浏览器地址。

### 构建安装包

```bash
npm run dist
```

构建完成后，安装包输出到 `release/`。其他常用命令：

```bash
npm run build   # 只构建前端资源
npm run lint    # 代码检查
```

首次安装依赖或构建安装包可能需要联网下载 Electron/NSIS 资源；应用安装完成后可以完全离线使用。

## 四、使用方法

### 快速开始

1. 从桌面快捷方式或开始菜单启动「键径 KeyPath」。
2. 第一次使用先打开「入门指南」，按六个步骤确认坐姿、基准键和手指分工。
3. 进入「训练」，从「入门」第 1 课开始。
4. 按屏幕提示输入，完成一节课后查看星级和成绩。
5. 达到当前等级的四项晋级条件后，进入下一等级；也可以到「挑战」测试速度。

### 训练

- 在左侧等级路线中选择等级；当前等级会显示 4 节课、晋级条件和进度。
- 点击课程卡片上的「开始练习」进入练习页；已完成的课程可以「再练一次」。
- 练习页顶部显示课程目标、难度和当前等级；中间是练习文本，下面是实时数据和虚拟键盘。
- 计时从第一次输入字符开始。按错键会增加失误、重置连击，但**不会移动光标**；按对当前字符后才继续。
- 按 `Esc` 可以随时退出练习，返回训练页或挑战页。
- 完成后会显示星级、速度、准确率、用时、失误和历史最佳。可以再练一次；满足条件时可以直接进入下一课。
- 星级按单课目标计算：同时达到目标速度和目标准确率为 3 星；准确率达到目标、速度达到目标的 80% 为 2 星；准确率达到 80% 为 1 星；否则为 0 星。重复练习会保留历史最高星级。
- 只有获得至少 1 星的课程才计入"完成全部课程"；0 星的一轮仍会记录练习次数和成绩，但不满足晋级条件。

### 挑战

- 在「挑战」页选择 30 秒、60 秒或 45 秒项目，点击「开始挑战」。
- 倒计时从第一次输入字符开始；顶部显示剩余时间、剩余失误机会（45 秒挑战）和实时成绩。
- 挑战结束后查看速度、准确率、失误和排名；有效成绩会获得 XP，排名进入本地前 10 名时还会出现在对应积分榜上。
- 45 秒挑战出现第 4 次失误会立即失败；失败局不计入榜单，也不获得 XP。
- 点击「再来一局」会生成新的挑战文本；点击「查看积分榜」可以查看当前项目的排名。

### 积分榜与昵称

- 在「积分榜」页的顶部输入昵称（最多 12 个字符），点击「保存」或让输入框失焦即可生效。
- 三个挑战各有独立的标签页和榜单；没有成绩时会显示「去挑战」入口。
- 「清空记录」只清除当前挑战的榜单记录，不会重置课程进度或 XP。
- 页面底部的「本机数据」显示当前实际数据文件路径；「清除全部数据」会删除文件并重置所有进度、昵称、设置和挑战记录。

### 数据保存

- 每次课程结算、挑战结算、修改昵称、切换音效或清空记录后，数据都会自动写入本机 JSON 文件。
- 正常关闭应用后再次启动，进度会自动恢复，不需要手动导入或导出。
- 首次产生用户数据时才会创建数据文件；如果只是打开应用而没有进行任何操作，数据文件可能暂时不存在。

### 输入建议

- 使用带实体键盘的电脑，保持英文输入状态；练习文本包含大小写字母、数字和符号。
- 优先保证准确率，再逐步提高速度；应用中的星级和晋级条件也以准确率为前置要求。
- 每次练习 10 到 15 分钟即可，累的时候停下来，避免用错误手位反复练习。

## 五、本机数据与清除

### 数据文件位置

默认位置是**应用安装目录下的 `keypath-data.json`**，与 `KeyPath.exe` 同级：

```text
<安装目录>\keypath-data.json
```

开发运行时，默认位置是项目根目录下的 `keypath-data.json`。

如果安装目录不可写（例如应用被放到了受保护的系统目录），应用会自动回退到 Electron 的用户数据目录，通常是：

```text
%APPDATA%\KeyPath\keypath-data.json
```

实际使用的路径会显示在「积分榜 → 本机数据」中，不需要猜。

### 文件内容

该 JSON 文件保存以下用户数据：

- 昵称和音效开关；
- 累计 XP；
- 每节课的练习次数、最佳星级、最佳速度和最佳准确率；
- 每个挑战的前 10 名记录；
- 数据创建时间。

文件由应用自动读写，采用临时文件替换的方式减少写入中断造成的损坏；不建议在应用运行时手动编辑。

### 清除全部数据

1. 打开「积分榜」；
2. 滚动到页面底部的「本机数据」区域；
3. 点击「清除全部数据」；
4. 在确认提示中点击「确认清除」。

清除操作会删除默认位置和回退位置中的数据文件及临时文件，并把当前界面重置为初始状态。该操作**无法撤销**，课程进度、昵称、XP、音效设置和挑战记录都会丢失。清除后不会立即生成空文件，下一次产生数据时会重新创建。

### 清除单个挑战

在「积分榜」中切换到对应挑战，点击「清空记录」并确认，即可只删除该挑战的榜单记录。课程进度、昵称和累计 XP 不受影响。

## 六、进度与晋级规则

### 单课星级

每节课显示自己的目标 WPM 和目标准确率：

- **3 星**：速度达到目标 WPM，且准确率达到目标准确率；
- **2 星**：准确率达到目标准确率，且速度达到目标 WPM 的 80%；
- **1 星**：准确率达到 80%（速度未达到 2 星要求也可以）；
- **0 星**：准确率低于 80%，本轮不计入"完成课程"。

每节课只保留历史最高星级；重复练习不会降低已获得的星级。

### 四个等级的晋级条件

每个等级有 4 节课、最多 12 颗星。以下四项**同时满足**才会解锁下一等级：

1. **完成全部课程**：本级 4 节课都至少获得 1 星；
2. **收集星星**：达到本级星级门槛；
3. **最佳速度**：本级课程中的最佳 WPM 达到门槛；
4. **平均准确率**：本级已完成课程的历史最佳准确率的平均值达到门槛。

| 等级 | 课程重点 | 星级要求 | 最佳速度 | 平均准确率 |
| --- | --- | --- | --- | --- |
| 入门 | 基准键、上排、下排、高频词 | 8 / 12 | 12 WPM | 89% |
| 中等 | 左右手分区、数字排、混合词 | 9 / 12 | 18 WPM | 91% |
| 老手 | Shift、标点、常用词、短句 | 10 / 12 | 28 WPM | 93% |
| 专家 | 符号、长句、数字混排、综合 | 10 / 12 | 36 WPM | 95% |

- 右上角的 `Lv.` 显示当前已解锁等级；等级由晋级条件决定，不消耗 XP。
- XP 是累计练习经验，用于成绩反馈，不直接决定等级解锁。
- 完成专家级的四项要求，即完成整条训练路线。

## 七、技术栈与目录

### 技术栈

- **Electron 45**：桌面窗口、单实例、本地文件读写；
- **React 19 + TypeScript**：界面与交互；
- **Vite 8**：前端构建；
- **electron-builder 26**：Windows NSIS 安装包。

主进程负责窗口、数据文件和 IPC；渲染进程通过最小化的 preload 桥接访问数据，启用了 `contextIsolation`、`sandbox`，并禁止新窗口和外部跳转。界面通过 `file://` 加载构建产物，不依赖 HTTP 服务。

### 目录结构

```text
electron/
  main.cjs              窗口、数据文件、IPC 和清除逻辑
  preload.cjs           暴露给渲染进程的数据桥接
build/
  icon.ico              应用与安装包图标
src/
  components/           训练、指南、挑战、积分榜、虚拟键盘、结算面板
  data/                 课程、键位、挑战题库
  hooks/                打字引擎
  lib/                  进度、文件存储、格式化、音效
  App.tsx               单页壳、导航和全局状态
  index.css             设计系统与响应式样式
electron-builder.yml    Windows 安装包配置
release/                构建后的安装包和未打包应用（生成物）
```
